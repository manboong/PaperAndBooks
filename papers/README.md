# Academic Papers

This directory contains notes and reviews for academic papers.

## Topics

- [Network Science](./network-science/) — stochastic block models, bipartite networks, community structure, and related methods.

## Convention

- File name: `YYYY-short-title.md`
- Keep bibliographic information near the top of each review.
- Record both the paper's contribution and your own interpretation/critique.
- Use the paper review templates in [`../templates/`](../templates/).
