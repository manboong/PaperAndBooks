# Books

This directory contains reading notes and reviews for books.

## Categories

### Literature

[`literature/`](./literature/) is for novels, short stories, plays, poetry, and other literary works.

Suggested focus: themes, characters, structure, style, interpretation, emotional response, and connections to other works.

### Nonfiction

[`nonfiction/`](./nonfiction/) is for philosophy, history, science, technology, society, essays, and other general nonfiction.

Suggested focus: thesis, core arguments, evidence, assumptions, critique, useful concepts, and possible applications.

## Convention

- File name: `author-short-title.md`
- One review per work.
- Put basic bibliographic information and reading date at the top.
- Spoilers are allowed, but mark them clearly when useful.
- Reviews may be written in any language.

Templates are available in [`../templates/`](../templates/).
